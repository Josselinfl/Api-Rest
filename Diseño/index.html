Documentacion

Endpoints disponibles

Todos los endpoints responden JSON y viven bajo el prefijo /api/v1. Pulsa Probar para ejecutar la peticion real contra tu servidor local.

Modelo relacional

  • categories 1 → N recipes
  • recipes N → M ingredients
  • Tabla puente recipe_ingredient con cantidad y nota

Codigos de estado

  • 200 lectura o actualizacion correcta
  • 201 recurso creado
  • 400 regla de negocio violada
  • 404 recurso o relacion inexistente
  • 409 conflicto de integridad referencial
  • 422 payload no valido (Pydantic)
  • 500 error interno del servidor
